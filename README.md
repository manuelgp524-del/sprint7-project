🚗 Vehicle Market Dashboard
Descripción

Este proyecto consiste en una aplicación web interactiva desarrollada con Python, Pandas, Plotly y Streamlit.

La aplicación permite explorar un conjunto de datos de anuncios de vehículos usados y analizar diferentes características de los vehículos mediante filtros, métricas y gráficos interactivos.

Funcionalidades

La aplicación permite:

📊 Consultar el número de vehículos disponibles.
💰 Visualizar el precio promedio de los vehículos.
🛣️ Analizar el kilometraje promedio.
📅 Consultar el año promedio de los vehículos.
🔎 Filtrar los vehículos por modelo.
🔎 Filtrar por condición.
⛽ Filtrar por tipo de combustible.
💵 Filtrar por rango de precio.
📅 Filtrar por año.
🛣️ Filtrar por kilometraje.
📊 Construir un histograma de precios.
🔵 Construir un gráfico de dispersión entre precio y kilometraje.
📈 Visualizar la evolución del precio promedio según el año.
🏆 Consultar los vehículos con los precios más altos.

Para ejecutar la aplicación localmente, primero activa el entorno virtual y después utiliza:

streamlit run app.py

La aplicación se abrirá en el navegador mediante la dirección local proporcionada por Streamlit.
